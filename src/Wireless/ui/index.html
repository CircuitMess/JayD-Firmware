      Cues

      Cue points aren’t available from the browser yet — the wireless API doesn’t expose cue state or commands. This panel will switch on once the firmware adds cue support.

      Track library

      Browsing and loading tracks from this page isn’t available yet. Load tracks using the device’s own screen and buttons.

      Needed follow-up API: a bounded GET /api/v2/library (paged, stable opaque track ids, no filesystem paths) plus a load_by_id action on POST /api/v2/command that resolves the id to a track on-device. Until that exists, this UI intentionally will not add an arbitrary path-based load.

      Help & status
      Read-only
      You can see live status but commands are blocked until you take control.
      Take control
      Requests exclusive control. Only one browser may control the device at a time.
      Control lost / expired
      Another browser took over, or this tab was inactive too long. Take control again to continue.
      Device restarted
      State resets and any prior control is dropped; commands are never resent automatically.
      Coach
      Advice only — it never changes playback by itself. Enable it to see suggested next tracks and mixing advice for the currently playing deck.
      Arm transition
      Starts a bounded, cancellable one-shot transition between two decks you choose. The target deck must already have a track loaded on the device; this page never loads a track by itself.
      Keyboard
      All controls are standard buttons, sliders and menus — Tab/Shift+Tab to move between them, Space/Enter to activate buttons, and arrow keys to adjust sliders and menus.
